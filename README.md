#  A Privacy-Centric Recreation Of The Blossom Project
******
The Blossom Project is a web app made by the community for the community that aims to help people track and plan: goals, milestones appointments, medication supply and usage.

We intend to keep this project free and built fully by the community.
## Privacy and Transparency
****
Every piece of data that you input in the app stays on your devices browser using persistent storage, this means nobody other than you has access to your data. 

Additionally, none of your data is being sold or used to train AI models and it never will. 

If you have further concerns the repository is free and open sourced which lets you look through each line and make sure nothings being collected. 

## Contribution
******
This project is still in early development and any and all contributions will undoubtedly help. Currently we are a team of 2 one in development and the other leading the project. 

Even if you don't know how to code you can still do many thing to help the project along, like testing out the app, finding bugs, and suggesting new features or ideas!
